## 12. Retention & LTV Optimization

### 12.1 Lifetime Value (LTV) Calculation
```
LTV = (Average Revenue Per User) × (Average Lifespan in Months)

Example:
ARPU = ₹150/month
Lifespan = 18 months
LTV = ₹150 × 18 = ₹2,700
```

**Goal**: Increase LTV by:
- Increasing ARPU (more purchases)
- Increasing lifespan (better retention)

---

### 12.2 Churn Prevention
**Identify at-risk users**:
- ML model predicts churn probability
- Proactive offers to at-risk users
- Personalized retention campaigns

**Example**:
- User with 70% churn probability gets exclusive offer
- "We noticed you haven't played. Here's 50% off Premium!"
